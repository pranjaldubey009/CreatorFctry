## About

**CreatorFctry** is a creative content studio focused on helping brands and creators build a stronger digital presence through high-quality content, visual storytelling, and creative strategy.

From social media content to personal branding, CreatorFctry brings everything together under one creative space.

## Services

- **Social Media Content** — Engaging content designed for modern social platforms.
- **Carousel Design** — Professional, storytelling-driven carousel posts.
- **Short-Form Video** — Reels, UGC-style videos and short-form content.
- **Personal Branding** — Content strategy and LinkedIn personal branding.
- **Thumbnail Design** — Visuals designed to capture attention and improve clicks.
- **Creative Strategy** — Content ideas, direction and brand storytelling.

## Website Features

- Modern, responsive design
- Dynamic portfolio showcase
- Services and packages section
- Testimonials section
- Inquiry and contact system
- Admin dashboard for content management
- Supabase-powered backend
- Portfolio asset management

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/pranjaldubey009/CreatorFctry.git
```

### 2. Navigate to the project

```bash
cd CreatorFctry
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Configure your Supabase credentials and other required environment variables in your development environment.

**Never expose service-role keys or private credentials in frontend code or public repositories.**

### 5. Run the development server

```bash
npm run dev
```

## Deployment

CreatorFctry is designed to be deployed using [Vercel](https://vercel.com).

Deployment requires appropriate environment variables and backend configuration.
